# Документы (sbe-documents)

SBE-плагин «Документы» — модуль документов, вынесенный из монолита `yougile-tntn`.
Реестр документов с файлами (S3), связанными документами и замечаниями, синхронизация
с сервером `documents-service` (`https://epyur.fvds.ru`) через JWT из ЦУП СБЕ.

## Требования

- Установлен и включён `sbe-apstore` (ЦУП СБЕ ПМиПИР).
- Есть доступ к серверу документов (роль выдаёт администратор; данные хранятся на
  сервере, локально — только кэш `yourbase/sbe_documents/`).

## Использование

Откройте плагин через ЦУП СБЕ ПМиПИР → «Установленные» → «Открыть» (у sbe-documents
собственных риббона и команд нет).

## Возможности

- Фасад «LogicTEAM.Документы»: топбар + сайдбар (сворачивание, навигация, «Фильтры»
  по типам, Синхронизация, Экспорт HTML) + контент-карточка.
- Карточки документов со вложенными связанными документами (рекурсивно; привязанный
  документ не имеет собственной карточки).
- Создание/редактирование документов, типы документов, срок действия, куратор.
- Привязка существующих документов («🔗 Привязать документы») и создание новых связанных
  («➕ Связанный документ»), отвязка («⤴ Отвязать»).
- Замечания к документу (№ элемента, текущая/предлагаемая редакция, обоснование, файлы).
- Загрузка файлов в S3 через сервис и скачивание: файл сохраняется в кэш вольта и
  открывается в Obsidian или системным приложением.
- Поиск по названию, фильтры по типам, завершение/возобновление документов.
